# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) como código de conducta. En resumen: respeto, empatía, crítica constructiva y cero acoso ni discriminación, en issues, PR y cualquier espacio del proyecto.

Para reportar una conducta inaceptable, usa el contacto privado de [SECURITY.md](SECURITY.md) o abre un aviso privado de seguridad en GitHub. Los mantenedores revisarán cada reporte con confidencialidad.
